# Cost-Aware Model Routing

Translate the task into hard capability and quality requirements, eliminate ineligible models, then choose the least-cost eligible model using measured quality, latency, and actual cost data. Preserve deterministic fallback behavior. Never use cost optimization to bypass safety, capability, authorization, or reliability constraints.

## Evidence
Public 2026 MCP inference and LLM gateway projects request multi-model routing, token accounting, and cost optimization. These are demand signals, not adoption measurements.
