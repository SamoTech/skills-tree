# Performance Profiling

1. Define the performance requirement and representative workload.
2. Capture a baseline using an appropriate profiler or measurement method.
3. Identify the dominant bottleneck from evidence.
4. Make the smallest targeted change.
5. Re-measure and run functional regression tests.
6. Record before/after evidence.

## Failure modes
- No baseline.
- Unrepresentative workload.
- Measurement noise treated as a real improvement.
- Correctness regression.
