# INVESTIGATION_LOG.md

# Append-only investigation log.
# Each entry should be added to the end of the file.

# Format for each entry:

Date:
[Date in YYYY-MM-DD format]

Question:
[Specific question being investigated]

Files Examined:
[List of files examined, with paths]

Evidence IDs:
[List of EVIDENCE-ID references created during this investigation]

Facts Created:
[List of FACT-ID references created during this investigation]

Decision Used:
[List of DECISION-ID references used during this investigation, if any]

Confidence:
HIGH/MEDIUM/LOW
[Overall confidence level for conclusions drawn in this investigation]

Next Action:
[Recommended next step based on this investigation]
