# FACTS.md

# Format for each fact:
FACT-ID:
Statement:
Status: CONFIRMED
Evidence:
EVIDENCE-ID

# Rules:
* No fact without evidence.
* No inferred facts.
* No speculative facts.

# Example:
FACT-001:
Statement: The skills-tree repository is a documentation/specification repository for AI agent skills with no executable runtime.
Status: CONFIRMED
Evidence:
EVID-001
