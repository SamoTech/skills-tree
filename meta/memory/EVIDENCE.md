# EVIDENCE.md

# Format for each evidence:
EVIDENCE-ID:
File:
[Absolute or relative path to the file]
Line Numbers:
[Starting line number]-[Ending line number] (or single line)
Quote:
[Exact quote from the file, including whitespace and punctuation as appears in the file]
Status:
VERIFIED

# Rules:
* Exact quotes only.
* No paraphrased evidence.
* No invented line numbers.
* No invented citations.

# Example:
EVID-001:
File: skills-tree/README.md
Line Numbers:
1-5
Quote:
# skills-tree
A repository for AI agent skills.
Status:
VERIFIED
