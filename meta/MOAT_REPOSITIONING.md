## The Three Virality Questions

### Why would someone STAR this repository?

1. **Utility** — `pip install skills-tree` gives them instant access to 368 structured skill definitions for their AI project
2. **Reference value** — It is the most comprehensive structured index of AI agent capabilities anywhere; they bookmark it
3. **FOMO signal** — "LATS vs ReAct benchmark with real numbers" — the kind of content that gets shared and saves time
4. **Discovery** — They search GitHub for "AI agent skills" and this is the definitive result
5. **Quality** — Battle-tested skills with typed I/O, runnable code, failure modes — not half-finished stubs
6. **Social proof** — If the star count is high enough, it signals "this is where the community landed"

### Why would someone CONTRIBUTE?

1. **Low barrier** — `cp meta/skill-template.md skills/category/my-skill.md` — the lowest-friction contribution model in the AI space
2. **308 stubs** — Obvious, pre-identified contribution targets; no need to invent what to build
3. **Attribution** — Every contributor appears in the git history of a widely-cited reference
4. **Learning** — Writing a skill forces you to understand it deeply; the process is educational
5. **Community recognition** — Skills you write get cited by other builders worldwide
6. **Resume signal** — Contributing to the canonical AI agent skills reference is a credible portfolio signal

### Why would someone SHARE it?

1. **"I found the answer"** — When someone asks "what are all the RAG retrieval strategies?", skills-tree is the shareable answer
2. **Benchmark shock value** — "LATS beats ReAct by 8.3% on HotpotQA" — this is the kind of result people screenshot and share
3. **Saved hours** — "I was about to reinvent this — found it already documented here" → genuine gratitude shares
4. **Teaching tool** — Educators and content creators share it as the reference for AI agent architecture courses
5. **Opinionated structure** — The 17-category taxonomy is a shareable framework for thinking about agent capabilities
6. **"The OS" framing** — "AI has a new OS for agent skills" is a narrative that travels well

## Moat Defense Strategy

The skills-tree moat deepens with every:
- New skill added (content moat)
- New requires edge added (graph moat — hard to replicate structure)
- New benchmark published (trust moat)
- New contributor (community moat)
- New integration (ecosystem moat — MCP, PyPI, LangChain, CrewAI)

**The graph structure is the hardest to replicate.** A link list (awesome-llm-apps) can be copied in a weekend. A versioned, dependency-graphed, benchmarked, community-governed taxonomy of 368+ skills with failure modes is a 2-year community project.
