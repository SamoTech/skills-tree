## Thread 2 — Roadmap (Post T-1, June 29)

**Category:** General  
**Title:** `🗺️ Skills Tree Roadmap — what’s coming and how to shape it`

**Body:**
```markdown
## Current State (v2 launch)

- 368 skills, 17 categories, 774+ dependency edges
- Interactive graph explorer with Featured Skills, Popular Paths, Surprise Me
- Blueprint Generator: 50 production agent architectures
- Python package (`pip install skills-tree`) + CLI + MCP server
- 10-language i18n

## Near-term (v2.x)

- [ ] Skill dependency graph — visual mini-graph in detail panel
- [ ] Skill Paths — structured learning sequences
- [ ] JSON/YAML export of the full taxonomy
- [ ] Community ratings per skill
- [ ] Analytics baseline (Explorer visits, blueprint generations)

## Medium-term (v3.0)

- [ ] 500+ skills milestone
- [ ] LangChain Hub / MCP registry integration
- [ ] Skill search by framework (LangChain, LlamaIndex, AutoGen…)
- [ ] Skill quality badges (community-verified vs auto-generated)

## Long-term

- [ ] Skills Tree as the canonical agent capability reference
- [ ] Skills as a training signal for agent evaluation

## What should we prioritize?

Reply with the number of the item you most want to see, or add your own.
```
