## HN Monitoring

**URL to watch:** https://news.ycombinator.com/submitted?id=[hn_username]

HN Rank benchmarks for Show HN posts:
- Front page (top 30): exceptional — 5,000+ views in 24h
- Page 2 (rank 31–60): good — 1,000–2,000 views
- Page 3+ (rank 61+): needs comment engagement to resurface

**Response protocol:**
- Reply to every comment within 2 hours of posting
- Answer technical questions with specifics, not marketing language
- Acknowledge criticism directly — HN penalizes deflection
- If a comment surfaces a real gap, open a GitHub issue immediately and link it in the reply
