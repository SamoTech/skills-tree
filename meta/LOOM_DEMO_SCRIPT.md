## Script

### 0:00 — Hook (30 sec)

> *"Marketing teams know they need AI agents. But nobody tells them which agents to build, how to structure the team, or what KPIs to target. I built something that answers all of that — in under a second."*

Show: Landing page. Hero section. Stats (50 goals, 368 skills).

---

### 0:30 — Context (45 sec)

> *"This is Marketing AI OS — a product surface built on top of Skills Tree, an open-source AI skill taxonomy with 368+ nodes. The key insight: the same skill graph that helps engineers build AI systems can be pointed at marketing goals."*

Show: Brief scroll of the goal list (left panel). Show category filters.

---

### 1:15 — Demo: Media Buying Blueprint (60 sec)

> *"Let's say your goal is to scale a Meta Ads campaign from $100/day to $1,000/day."*

Action: Click Goal #03 — "Scale a winning ad set from $100/day to $1,000/day"

> *"Instantly, the system generates: the AI agent team you need — Campaign Orchestrator, Audience Analyst, Bidding Strategist. The required AI skills from the graph. KPI targets — ROAS ≥ 3.0×, CPA < $45. And a 30-day execution timeline."*

Show: Blueprint output in detail. Hover over agent cards.

---

### 2:15 — Demo: Agent Team Blueprint (45 sec)

> *"Now let's try something more advanced — building a full media buying AI agent team from scratch."*

Action: Click Goal #22 — "Build a media buying AI agent team"

> *"Same pattern: supervisor agent, specialists, evaluator with a reflection loop. The handoff protocol, the KPI matrix, the deployment timeline — all generated deterministically from the skill graph."*

---

### 3:00 — Demo: Landing Page Audit (30 sec)

> *"One more — auditing a landing page for conversion."*

Action: Click Goal #16 — "Audit and score a landing page for conversion"

Show: CRO Auditor agent, CVR ≥ 3.5% KPI, Audit-Fix-Test-Report timeline.

---

### 3:30 — Architecture (45 sec)

> *"Under the hood: zero runtime API calls. No hallucination. No latency. The blueprint engine is 100% client-side JavaScript running against a static skills graph. It's forkable, self-hostable, and fully open-source on GitHub."*

Show: GitHub repo. Point to `docs/marketing-os/app.js` and `meta/MARKETING_GOAL_CATALOG.md`.

---

### 4:15 — Closing (30 sec)

> *"Marketing AI OS turns any marketing goal into a deployable AI system. No LLM required at runtime. No SaaS lock-in. The full taxonomy, the architecture docs, and the live demo are all in the Skills Tree repo. Link is in the submission."*

Show: Return to landing page. End on hero.
