## Virality Mechanisms

### 1. Shareable Deep Links
Every blueprint has a unique URL: `/blueprints/?goal=<id>`
URL is auto-generated and copy-button accessible.

### 2. Markdown Export
Users paste blueprints into Notion, GitHub READMEs, Discord, blog posts.
Each export includes: `Generated by Skills Tree Blueprint Generator`
This creates passive backlinks.

### 3. JSON Export
Developers embed blueprints into tooling, scripts, pipelines.
Attribution included in `version` field.

### 4. Show HN / Reddit
Blueprint Generator is a natural Show HN post:
- Technical audience
- Immediately useful
- No signup required
- Visually compelling output

### 5. Community Contributions
Each blueprint is a spec. Community contributors can:
- Submit new goals via GitHub Issues
- PR new skill nodes to match goals
- Extend the catalog to 100+ goals
