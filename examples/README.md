# Skills Tree Examples

Runnable, production-quality examples demonstrating Skills Tree in real scenarios.

| Directory | What it shows | Difficulty |
|---|---|---|
| [`openai-agent/`](openai-agent/) | Skill-aware OpenAI agent | Beginner |
| [`mcp-server/`](mcp-server/) | MCP server for Claude Desktop | Intermediate |
| [`recommendation-engine/`](recommendation-engine/) | Learning path recommender | Intermediate |
| [`rag-system/`](rag-system/) | RAG pipeline with skill context | Advanced |
| [`enterprise-agent/`](enterprise-agent/) | Multi-agent orchestration + audit | Advanced |

## Prerequisites

```bash
pip install skills-tree
```

Each example has its own `requirements.txt` for additional dependencies.
