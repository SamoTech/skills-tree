# Skills Tree — The Definitive AI Knowledge Platform

> **Vision:** Become the Wikipedia of AI agent capabilities — the canonical, community-owned reference every agent engineer, researcher, and AI-native team uses as their foundation.

---

## Why This Must Exist

The AI agent ecosystem is exploding. New frameworks appear weekly. MCP servers multiply daily. Patterns proven in research reach production months later with zero institutional memory. Knowledge is scattered across:

- 500+ GitHub repos with no cross-links
- Discord threads that expire
- Private Notion docs at companies
- Papers with no production counterparts
- Benchmarks that can't be reproduced

**Skills Tree is the fix.** One open, free, versioned, machine-readable platform that maps the entire AI capability landscape — from raw LLM primitives to production multi-agent architectures.

## Core Principles

1. **Free forever.** No premium tier. No feature gates. No paywalls. No exceptions.
2. **Community-owned.** No single company controls the roadmap. PRs determine what ships.
3. **Machine-readable first.** Every piece of content has a structured data counterpart.
4. **Opinionated quality.** Not a link dump. Battle-tested means battle-tested.
5. **Ecosystem-neutral.** We document LangChain, LlamaIndex, and every other framework equally.
6. **Sponsor-supported, not sponsor-controlled.** Sponsors fund infrastructure; community decides content.

## The Three Audiences

### Agent Builders (Primary)
Production engineers building real systems. They need:
- Copy-paste patterns that work today
- Honest failure modes (what breaks at scale)
- Model comparison data
- Architecture blueprints

### AI Researchers (Secondary)
Academics and lab engineers. They need:
- Structured taxonomy that maps to papers
- Reproducible benchmarks
- Capability coverage maps
- Machine-readable data for meta-analysis

### Learners (Growing)
Engineers entering agent development. They need:
- Structured learning paths
- Difficulty-rated content
- Visual knowledge maps
- Clear "start here" guidance
