# Skills Tree — Vision Document

> *From repository to platform. From documentation to infrastructure.*

---

## The North Star

Skills Tree becomes **the definitive global knowledge platform for AI capabilities, AI agents, MCP tools, AI workflows, and agent engineering** — the canonical reference every agent framework, researcher, practitioner, and builder links to.

Think at the level of:
- **Kubernetes** → canonical infrastructure reference
- **MDN Web Docs** → authoritative, community-driven, always current
- **Hugging Face** → the platform effect — models, datasets, spaces, community
- **roadmap.sh** → visual, opinionated, learner-first
- **Home Assistant** → open source, integrations-first, ecosystem dominance
- **LangChain** → practitioner-first, framework-agnostic at the data layer

**We are not a list. We are not docs. We are a platform.**

## What We Are Building

### 1. Skills Explorer
An interactive discovery experience. Users browse, filter, and traverse the AI capability space visually — not through a flat list, but through a living knowledge graph.

### 2. Capability Search Engine
Semantic search across every skill, framework, use case, difficulty level, domain, and agent type. Powered by open-source embeddings. Results ranked by community quality signals.

### 3. Agent Builder
User describes a goal in plain language. The platform generates:
- Required skills inventory
- Recommended architecture
- Suggested tools and frameworks
- MCP tool recommendations
- Step-by-step implementation path

### 4. MCP Explorer
The definitive ecosystem explorer for Model Context Protocol:
- MCP Servers catalogue
- MCP Clients catalogue
- MCP Tool patterns
- Integration recipes
- Community ratings

### 5. AI Capability Database
Every skill is a structured record in a machine-readable database. Queryable via API. Exportable as JSON, YAML, CSV. Embeddable in third-party tools.

### 6. Visual Knowledge Graph
The entire AI ecosystem navigable as an interactive force-directed graph. Traverse from Memory → Vector Store → RAG → Chunking → Embedding in three clicks.

### 7. Learning Platform
Curated learning paths for specific goals:
- "Build a production RAG system in 5 days"
- "Master multi-agent orchestration"
- "From LLM calls to autonomous agents"

### 8. API Platform
Public REST + GraphQL API. Rate-limited but free. Powers the web UI and third-party integrations.

### 9. Contributor Dashboard
Reputation, streaks, leaderboards, contribution graphs, hall of fame, monthly challenges.

### 10. Sponsor Portal
Transparent sponsor recognition. Corporate backers. Ecosystem partners. No user-facing restrictions.
