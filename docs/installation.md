# Installation

Skills Tree requires Python 3.9 or higher.

## From PyPI (Recommended)

```bash
pip install skills-tree
```

## With Extra Dependencies

```bash
# With MCP server support
pip install skills-tree[mcp]

# With all extras
pip install skills-tree[all]
```

## From Source

```bash
git clone https://github.com/SamoTech/skills-tree.git
cd skills-tree
pip install -e .
```

## Verify Installation

```bash
skills-tree --version
skills-tree list
```

## Requirements

- Python ≥ 3.9
- Dependencies listed in `pyproject.toml`

See [Quick Start](quickstart.md) for your first steps after installation.
